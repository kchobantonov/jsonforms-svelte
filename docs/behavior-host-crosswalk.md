# Behavior vector production-host crosswalk

The [conformance results](conformance-results.md) record execution of all 23 exact imported behavior vectors in their declared adapter scopes. This crosswalk asks a different question: which invariant is also asserted by a built-demo test across the three renderer families, English/Bulgarian and native/Web Component hosts? A linked demo is an **analog**, not execution of the exact imported input. `Gap` means the exact adapter passes but the cited production journey does not assert the whole invariant. The default `demoTest` matrix is 3 families × 2 locales × 2 hosts; host-restricted tests are called out.
