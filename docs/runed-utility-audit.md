# Runed utility audit

Reviewed against the public [Runed utility documentation](https://runed.dev/docs/utilities/debounced) and the installed `runed@0.35.1` package on 2026-10-26. The shadcn demo and shadcn Web Component already depend on Runed for the adopted Stepper. Other renderer packages do not depend on it directly. This audit is about reducing maintained code without changing form commit, URL, storage, or focus behavior; it is not a new spec-parity requirement.

**Applied:** The shadcn demo header in [`+layout.svelte`](../apps/jsonforms-svelte-shadcn-demo/src/routes/+layout.svelte) now uses [`useResizeObserver`](https://runed.dev/docs/utilities/use-resize-observer) for automatic target tracking and cleanup. It still measures synchronously on mount so the CSS header offset is ready before the observer callback.

## Concrete opportunities and boundaries

| Utility                                                                                                                                                                                                       | Existing code                                                                                                                                                                                                                                                 | Decision                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`PersistedState`](https://runed.dev/docs/utilities/persisted-state)                                                                                                                                          | [`useLocalStorage`](../packages/jsonforms-svelte-demo-common/src/lib/store/index.svelte.ts) stores layout, locale, theme, mode, and design-system preferences for all demos.                                                                                  | The shared adapter now migrates legacy raw keys into versioned values and handles invalid or blocked storage. Runed still has different default-write, cross-tab and null-removal behavior. A replacement needs to preserve this new storage contract and pass its focused migration/fallback tests.                                       |
| [`useSearchParams`](https://runed.dev/docs/utilities/use-search-params)                                                                                                                                       | [`useHistoryHashQuery`](../packages/jsonforms-svelte-demo-common/src/lib/store/index.svelte.ts) stores demo controls after the `#` in hash routes.                                                                                                            | Not a drop-in replacement. Runed's Kit helper reads/writes ordinary URL search parameters before the fragment and has different history/default behavior. A switch would change shareable example URLs. Use it for a future route with real `?query` parameters.                                                                           |
| [`Debounced`](https://runed.dev/docs/utilities/debounced)                                                                                                                                                     | Search terms in the demo sidebar; draft inputs in [`textInput.svelte.ts`](../packages/jsonforms-svelte/src/lib/textInput.svelte.ts).                                                                                                                          | Suitable for a future expensive, _derived_ search result. Current sidebar filtering is cheap and immediate. Do not substitute a delayed value for form drafts: IME completion, blur flush, stale-schema cancellation, pending dialog edits, and permission revocation are part of the current contract.                                    |
| [`useDebounce`](https://runed.dev/docs/utilities/use-debounce)                                                                                                                                                | The three renderer families use Lodash debounce in `util/composition.svelte.ts`; text inputs and section-indicator hover have explicit timers.                                                                                                                | Investigate only with behavioral tests. Lodash `.flush()` is synchronous, while Runed's `runScheduledNow()` returns a promise and its `cancel()` rejects a pending promise. The pending-edit coordinator depends on synchronous flush/cancel behavior. Hover timers and toast delays have different semantics from debounced form commits. |
| [`useResizeObserver`](https://runed.dev/docs/utilities/use-resize-observer) / [`ElementSize`](https://runed.dev/docs/utilities/element-size) / [`ElementRect`](https://runed.dev/docs/utilities/element-rect) | Demo header (converted); [`splitPane.svelte.ts`](../packages/jsonforms-svelte/src/lib/splitPane.svelte.ts), [`dialogGeometry.svelte.ts`](../packages/jsonforms-svelte/src/lib/dialogGeometry.svelte.ts), and Monaco editor sizing still use manual observers. | Evaluate per owner. The split pane measures separator widths and gaps, the dialog has viewport constraints, and Monaco must call `editor.layout()` at particular points. A simple observer swap may be possible, but the geometry and lifecycle logic remains custom.                                                                      |
| [`useMutationObserver`](https://runed.dev/docs/utilities/use-mutation-observer)                                                                                                                               | [`LocalizedCalendar.svelte`](../packages/jsonforms-svelte-shadcn/src/lib/controls/components/LocalizedCalendar.svelte), calendar announcements, Flowbite datepicker/split handles, and Monaco theme tracking.                                                 | Good candidate where only observer setup/cleanup is custom. Translation callbacks must still reapply when locale changes, and observers that write observed attributes need their existing loop guard. Adoption in renderer packages adds a direct runtime dependency; test locale changes and cleanup first.                              |
| [`useEventListener`](https://runed.dev/docs/utilities/use-event-listener)                                                                                                                                     | Global media, hash, keyboard, and pointer listeners in demo layouts and renderer overlays.                                                                                                                                                                    | Useful for stable listeners on external targets. Drag and popup listeners intentionally exist only during an interaction and require capture/passive options or ordered teardown; keep that ownership explicit unless a replacement is demonstrably simpler.                                                                               |
| [`onClickOutside`](https://runed.dev/docs/utilities/on-click-outside)                                                                                                                                         | Shadcn [`SectionIndicators.svelte`](../packages/jsonforms-svelte-shadcn/src/lib/layouts/SectionIndicators.svelte) closes a validation summary on outside pointerdown.                                                                                         | Possible, but the summary is portaled and both trigger and panel count as inside; verify composed paths across Web Component shadow boundaries before adopting.                                                                                                                                                                            |

## Full public utility inventory

The remaining utilities were checked for matching code and contract fit. “No current fit” means no worthwhile replacement in this repository today, not that the utility is unsuitable in general.

| Group      | Utilities                                                                                                                                                                                                                                                                                                                                                                                                                                     | Assessment                                                                                                                                                                                                                                                                                                                       |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reactivity | [`extract`](https://runed.dev/docs/utilities/extract), [`resource`](https://runed.dev/docs/utilities/resource), [`watch`](https://runed.dev/docs/utilities/watch)                                                                                                                                                                                                                                                                             | `watch` is already used by the adopted Stepper. `extract` helps a reusable API accepting values/getters; existing app helpers are mostly concrete. `resource` may fit a future async view, but schema loading and editor diagnostics have ownership/cancellation rules that a generic async wrapper would not replace by itself. |
| State      | [`Context`](https://runed.dev/docs/utilities/context), [`FiniteStateMachine`](https://runed.dev/docs/utilities/finite-state-machine), [`Previous`](https://runed.dev/docs/utilities/previous), [`StateHistory`](https://runed.dev/docs/utilities/state-history), [`Throttled`](https://runed.dev/docs/utilities/throttled)                                                                                                                    | `Context` is already used by the adopted Stepper. Form branch changes are transactional, not a simple state machine. Previous/history are not a substitute for JSON Forms data ownership or editor undo. No current scroll/input throttling would be simplified enough to justify an added dependency.                           |
| Elements   | [`activeElement`](https://runed.dev/docs/utilities/active-element), [`IsFocusWithin`](https://runed.dev/docs/utilities/is-focus-within), [`IsInViewport`](https://runed.dev/docs/utilities/is-in-viewport), [`ScrollState`](https://runed.dev/docs/utilities/scroll-state), [`TextareaAutosize`](https://runed.dev/docs/utilities/textarea-autosize), [`useIntersectionObserver`](https://runed.dev/docs/utilities/use-intersection-observer) | Potential helpers for new UI. Current focus restoration uses an explicit owned target, and popup bounds depend on geometry and scrolling context. Existing textareas do not appear to duplicate a generic autosize hook. No current custom intersection observer was found.                                                      |
| Sensors    | [`IsDocumentVisible`](https://runed.dev/docs/utilities/is-document-visible), [`IsIdle`](https://runed.dev/docs/utilities/is-idle), [`PressedKeys`](https://runed.dev/docs/utilities/pressed-keys), [`useGeolocation`](https://runed.dev/docs/utilities/use-geolocation)                                                                                                                                                                       | No current fit. Pointer/keyboard interactions require specific event sequences rather than a global pressed-key snapshot.                                                                                                                                                                                                        |
| Animation  | [`AnimationFrames`](https://runed.dev/docs/utilities/animation-frames)                                                                                                                                                                                                                                                                                                                                                                        | No current fit. The existing animation-frame calls coordinate one-shot layout work, not a running animation loop.                                                                                                                                                                                                                |
| Utilities  | [`boolAttr`](https://runed.dev/docs/utilities/bool-attr), [`onCleanup`](https://runed.dev/docs/utilities/on-cleanup), [`useInterval`](https://runed.dev/docs/utilities/use-interval), [`useThrottle`](https://runed.dev/docs/utilities/use-throttle)                                                                                                                                                                                          | No clear maintenance win. Existing boolean attributes and component teardown are simple; no custom recurring interval loop was found. Throttling form writes would change validation timing.                                                                                                                                     |
| Component  | [`IsMounted`](https://runed.dev/docs/utilities/is-mounted)                                                                                                                                                                                                                                                                                                                                                                                    | No current fit beyond straightforward Svelte `onMount`/browser guards.                                                                                                                                                                                                                                                           |

Follow-up order if more consolidation is wanted: (1) decide whether Runed can preserve the now-tested versioned migration, invalid-value fallback and cross-tab contract; (2) localized calendar/date-picker mutation observers with locale and Web Component tests; (3) standalone demo/global listeners. Keep the pending form edit helpers on their current implementation unless equivalent synchronous flush, cancellation, and unmount behavior are demonstrated.
