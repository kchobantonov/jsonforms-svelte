## Catalog adapter acceptance

- Derive registration dynamically from the spec package export; assert catalog IDs and demo IDs match exactly after applying `spec-`.
- Preserve optional `schema`, `uischema`, and `data`; do not default missing values to `{}` or `null`.
- Keep translations editable as data and rebuild translators reactively. Functions/testers/native hooks remain trusted host registrations outside editable JSON.
- Preserve/display hostRequirements. Some requirements mention React-specific adapters; implement the equivalent Svelte capability and document it.
- Load trusted `uischemas.mjs` exports where provided, including array-detail-modes, editor-details, object-control, template-slots, tuple-control, and any future catalog registry.
- Do not let an empty `translations` asset or an English fallback stand in for Bulgarian acceptance.
- Keep a per-example result for loading, interaction, validation, locale and host parity. Record skipped capabilities with reasons; do not mark a mount-only run as feature conformance.
- Test source links, percent-encoded deep links, direct load/back/forward, catalog additions and native-hook overrides independently of fixture enumeration.

## Root inference and generic JSON examples

`spec-json-inference` preserves omitted schema and data; `spec-json-editor` preserves its authored `{}` and omitted data. Their source JSON and EN/BG catalogs are imported without semantic edits. Core inference handles scalar, array, object and null roots and recomputes after root replacement. All three complete registries have browser coverage for string/array edits, external null replacement, and absent/string/absent transitions with omitted or unrestricted schemas. The Data, Schema and UI Schema editors interpret blank/whitespace as absent. Clearing Schema removes only that editor's Monaco schema association. The inference editor flow passes in all three production demos, in EN/BG and native/Web Component modes. It covers every JSON root type, number-to-zero and false-to-true edits, object edits, invalid JSON, explicit/cleared schema, cleared/reloaded UI schema and absent data reload. The focused core run adds 30 passing cases, including external type replacement and original boolean-schema errors. Generic JSON code/tree/nested acceptance remains pending.
