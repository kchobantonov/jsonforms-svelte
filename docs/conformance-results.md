### Adapter details

- `port-branch-feedback` adds branch titles to request identifiable branch views. Validation assertions remain unchanged. The test distinguishes ordinary branch-selection inference from extra displayed-branch validation and verifies the latter stops when disabled.
- `port-summary-search` supplies the described Label presentation through `options.markup`, enables dynamic values, and checks AG Grid's displayed text, filter result and retained row identity.
- `port-choice-reload` now mounts the exact imported object-enum vector in all three native families, then replaces host data with an independently parsed equivalent JSON object. Each adapter verifies that the first choice remains selected and the stored value remains an object with the original JSON content; the three focused cases and package Svelte checks pass.
- The related canonical `spec-choice-controls` browser journey now reapplies an independently serialized but equivalent object selection with the member order reversed. Its **12/12** family × EN/BG × native/Web Component cases retain the selected `choice-0` radio value and row-cell choice and verify the complete saved JSON. This extends the equality invariant to production hosts; the exact imported vector remains the native adapter evidence above.
- Shadcn's `pending-delete` adapter selects the target table row and activates its toolbar Delete command, matching that native family's selected-row action. It waits for selection state before deletion, then verifies the imported `["Sam"]` result and checks that the queued edit cannot reappear after the debounce. The other two families use their per-row Delete commands. The eight current behavior adapter files pass 60/60 focused cases.
- Change counts exclude the initial JSONForms state notification. Data edits and actions are observed after mounting.
- Duration also runs in Bulgarian. Other behavioral vectors use English; wider EN/BG acceptance remains in the example matrix.
- These results establish the tested native profiles. They do not establish keyboard, visual, Web Component or all-option parity for every renderer.
- The [production-host crosswalk](behavior-host-crosswalk.md) reconciles all 23 vectors: 22 production analogs and one accepted shared-core path-indexing scope. Focused added journeys pass 12/12 for unchanged duration, obfuscated script URL, tuple prefix and boolean cell-error placement, plus 6/6 Web Component cases each for accordion close and template host data replacement. An analog does not execute the exact imported vector.

## Gaps found and fixed

- Declared dotted and empty property names aliased nested dot paths. A shared literal-key boundary now retains unrelated data, references, permissions and validation locations. Native aggregate mixed-object editors now use the same boundary without blanket readonly. Visible/searchable labels and all three template profiles use the current JSON Forms context. Literal editors are rooted at their selected value, matching React; dialog drafts copy that context without an additional data abstraction. Later rule/error-context collision tests and 18/18 literal-path checkpoints close P1.3; the preceding literal-property/duration batch passed all 24 production scenarios across hosts.
- Applying unchanged duration parts rewrote imported equivalent spellings such as `P0W`. It now preserves the original value; picker text uses JSON catalogs.
- Label summaries returned raw Markdown for filtering. They now use displayed text, escape substitutions and load the parser lazily.
