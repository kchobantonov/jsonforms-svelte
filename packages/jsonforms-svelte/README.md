# @chobantonov/jsonforms-svelte

Svelte 5 bindings for JSON Forms. Use `JsonForms` with a JSON Forms renderer registry. The package provides renderer and cell dispatch, the unknown-renderer fallback, form context and renderer bindings for `@jsonforms/core`.

## Installation

```bash
npm install @chobantonov/jsonforms-svelte
# or
pnpm add @chobantonov/jsonforms-svelte
```

For the Flowbite, shadcn and Skeleton renderer families, use the extension-aware host from [renderer-common](../jsonforms-svelte-renderer-common/README.md). The [migration guide](../../docs/migration-and-release-notes.md#choosing-the-svelte-host) lists the host import for each setup.
