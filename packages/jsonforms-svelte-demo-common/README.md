# @chobantonov/jsonforms-svelte-demo-common

Private shared library for Svelte demo applications in this monorepo.
It contains reusable demo-only modules such as examples, AJV/validation helpers,
Monaco/schema helpers, and shared store utilities.

The [demo shell catalogs](src/lib/i18n) contain one TypeScript module per language. Keep example-specific translations with the example data. See the [catalog guide](../../docs/i18n-catalogs.md) for key checking, registration and fallback behavior.
