# Tree with a maximum depth

Root counts as level 1. Five finite node definitions replace unbounded recursion. Level 5 folders use maxItems: 0 and items: false. File and Folder layouts are shared through the registry. Imported deeper data is invalid; the schema, not visual collapse, enforces the limit.

Node unions have an explicit empty-object default. Add leaves Kind unselected; selecting File or Folder applies its whole-object default. Clearing an object-only child retains its slot as {}.
