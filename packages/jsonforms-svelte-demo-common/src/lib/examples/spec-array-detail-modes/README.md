# Array detail modes

Register the trusted uischemas.mjs entries before rendering this example.
DEFAULT shows the ordinary table for these flat items. GENERATE (shown lowercase)
renders both fields despite a matching registered layout. REGISTERED shows only
Registered name. The fallback collection has no registry match and shows both
fields. Inline uses the supplied horizontal layout and labels. GENERATED also
shows Registered name: upstream core recognizes GENERATE for forced generation.

All controls edit separate copies of the same sample values. Inline and registered
layouts intentionally omit fields without deleting those values.
